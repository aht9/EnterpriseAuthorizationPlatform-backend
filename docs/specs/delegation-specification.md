# Delegation Specification

Version: 1.0

---

# Purpose

Temporary transfer of permissions.

---

# Example

FinanceManager on vacation.

Permission delegated to deputy.

---

# Delegation Rules

Must have:

StartDate

EndDate

Reason

CreatedBy

---

# Restrictions

Delegation cannot exceed owner permissions.

---

# Approval

Sensitive permissions require approval.

---

# Audit

Every delegation must generate audit event.

---

# Expiration

Automatic revocation required.

---

# Emergency Delegation

Supported.

Requires post-review audit.
